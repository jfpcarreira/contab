Contab privacy policy

Last updated: 17 October 2026

Who uses this application

Contab is a private application with a single user, its owner João Carreira. It is not available to anyone else.

What Google data it accesses

With the owner's authorisation, Contab uses the Google Drive API to list, download, upload, move and rename files inside the owner's "Empresa" folder in Google Drive. It does not access files outside that folder.

How the data is used and stored

Documents are read only to record accounting data in the owner's own database, which runs on infrastructure controlled by the owner. Temporary copies are deleted after processing. Data is never sold, shared with third parties or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
